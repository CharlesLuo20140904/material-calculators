A roll count based on drops—not square footage.

1. Count strips by wall

Each wall width is divided by roll width and rounded up independently, so offcuts are not assumed to continue around corners.

2. Match the pattern

Straight matches round every cut to the repeat. Half-drop matches alternate the pattern position and may require longer cuts.

3. Pack full rolls

Matched cut lengths are packed into the physical roll length, then the optional repair roll is added.

Common questions

Before checkout

Should I subtract doors and windows?

Usually no. Installers still cut strips for the wall above and below ordinary openings. Deduct only a full-height opening that genuinely removes one or more complete drops.

Why does half-drop use more paper?

Every other strip starts at a shifted point in the design. That alternating alignment can require a longer cut and leaves more unused length on each roll.

Is the reserve roll included in the result?

Yes, when the checkbox is selected. The base roll estimate is shown separately so the allowance is transparent.
