Before you order

Read the roll label twice.

01

Enter the packaged roll size

Single-roll and double-roll naming varies. Use the physical width and length printed on the product label.

02

Use the vertical repeat

A straight or drop match can consume extra length even when the total square footage appears sufficient.

03

Keep one run number

Order the project together and confirm every roll has the same dye-lot or run number before cutting.
