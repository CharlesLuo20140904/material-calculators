Open a public GitHub issue

Use the repository’s issue form for calculation errors, broken links, source updates, accessibility problems, and unclear instructions.

Create an issue

The issue tracker is operated by GitHub and is public. A GitHub account may be required. If the report contains information you do not want published, do not submit it through this route.

What makes a report actionable

  1. Copy the exact Project Matter page URL.
  2. List the measurement system and calculator inputs without identifying the property.
  3. State the displayed result and the result you expected.
  4. Link the current product data sheet, installation guide, or other source when the disagreement concerns coverage or yield.
  5. Describe the browser and device only when the issue is visual or interactive.

What this route can address

Calculations

Formula errors, rounding mistakes, unit conversion, package quantities, or worked examples.

Sources

Moved links, revised product data, outdated terminology, or a stronger primary source.

Accessibility

Keyboard use, labels, focus, contrast, zoom, motion, mobile layout, or screen-reader output.

Privacy

Questions about local calculations, analytics choices, advertising scripts, or third-party requests.

What to expect

Reports are reviewed according to impact. A calculation error that changes purchase quantity takes priority over wording or visual preference. A correction may result in a code change, a source replacement, a clearer limitation, or an explanation of why the existing calculation is intentional.

This route cannot provide a supplier quote, building design, permit advice, engineering review, or project-specific installation approval. For those decisions, contact the product manufacturer, supplier, building authority, or a qualified local professional.
